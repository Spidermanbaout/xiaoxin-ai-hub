# 小新AI资讯工具站 · XiaoXin AI News & Tools Hub

AI 资讯与工具站，面向新手，服务于抖音“小新AI课堂”频道。Kiroween 2026 参赛作品（Frankenstein 组）。

An AI news and tools website for beginners, made for the "小新AI课堂" Douyin AI tutorial channel. Kiroween 2026 entry (Frankenstein).

## 功能 · Features

- **资讯速览**：每日 AI 资讯，分大模型、产品工具、行业公司、开源项目、政策应用五类，可筛选
- **工具导航**：12 个新手常用 AI 工具，可搜索、可按场景筛选，附官网链接与免费额度说明
- **羊毛雷达**：AI 免费额度、免费试用与限免福利，美国平台优先
- **提示词工坊**：5 种场景一键生成提示词，可复制
- **选题助手**：输入关键词，生成 8 条抖音标题

## 本地使用 · Run locally

直接用浏览器打开 `index.html` 即可，无需安装与构建。

Open `index.html` in a browser. No install or build step needed.

## 怎么做的 · How it was built

- 网站初版由 Muse（Meta 的 AI 助手）搭建：页面、内容与两个在线小工具。
- Kiro IDE（Free）负责规范层：`.kiro/steering/`（产品、技术、结构）与 `.kiro/specs/ai-news-tools-site/`（需求、设计、任务清单），并对照规范审阅了代码。详情见 [KIRO.md](KIRO.md)。
- 仓库里的 `.kiro/` 目录就是 Kiro 实际产出的文件。
