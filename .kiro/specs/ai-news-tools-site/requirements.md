# 小新AI资讯工具站 - 需求文档

## 1. 项目概述

为抖音频道"小新AI课堂"创建一个静态单文件网站，作为AI资讯和工具的入口页。

## 2. 功能需求

### 2.1 资讯速览（News）
- 展示今日精选AI资讯（9条）
- 资讯分类：大模型、产品工具、行业公司、开源项目、政策应用
- 热门资讯置顶展示
- 支持搜索关键词过滤
- 支持标签筛选

### 2.2 工具导航（Tools）
- 展示12个亲测分类的AI工具
- 每个工具卡片包含：图标、名称、简介、直达链接
- 工具分类：大模型、文生图、视频生成、音频生成、办公效率等

### 2.3 羊毛雷达（Freebies）
- AI工具免费额度/赠金情报
- 显示免费额度详情和领取入口
- 标注"免费"标签

### 2.4 提示词工坊（Prompt Workshop）
- 在线提示词生成工具
- 输入主题/关键词，生成适合AI的提示词
- 一键复制生成结果

### 2.5 选题助手（Title Assistant）
- 短视频选题生成工具
- 输入关键词，生成10个短视频标题
- 一键复制标题

### 2.6 参赛提交包（Submission Pack）
- Devpost参赛提交模板
- 包含项目描述、技术栈、功能介绍等字段
- 一键复制模板

## 3. 非功能需求

### 3.1 性能
- 页面加载时间 < 2秒
- 首屏渲染 < 1秒

### 3.2 响应式
- 支持桌面端（1920px+）
- 支持平板端（768px-1024px）
- 支持移动端（320px-767px）

### 3.3 无障碍
- 足够的对比度
- 键盘导航支持
- 语义化HTML

### 3.4 亮度模式
- 支持亮色/暗色主题切换
- 记住用户偏好

## 4. 内容需求

- 今日日期显示
- 6个模块的入口导航
- Hero区介绍文案
- 统计数据展示（9条资讯、12个工具、6项免费、2个工具）
